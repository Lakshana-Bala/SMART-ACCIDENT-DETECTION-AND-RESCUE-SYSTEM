Smart Accident Detection & Rescue System

## About the Project
The **Smart Accident Detection & Rescue System** is a student demonstration prototype designed to showcase an accident-reporting workflow. It provides a dashboard to simulate accident alerts, enter location coordinates, view locations on OpenStreetMap, and export demo records as a CSV file.

##  Features
- Upload and preview a road or vehicle image.
- Manually select a demo accident outcome.
- Enter and validate latitude and longitude.
- Generate simulated accident alerts.
- View demo records in a monitoring dashboard.
- Open the selected coordinates in OpenStreetMap.
- Download alert records as a CSV file.
- Reset the form and clear demo records.

##  Technologies Used
- HTML
- CSS
- JavaScript
- OpenStreetMap

## Current Implementation
The current version demonstrates the user interface and simulated accident-reporting workflow. Alert records are stored temporarily in browser memory while the page remains open.
